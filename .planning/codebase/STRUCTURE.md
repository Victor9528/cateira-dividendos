## Naming Conventions

**Files:**
- Module files: lowercase with `.js` extension, e.g., `state.js`, `ui.js`, `api.js`
- One special case: `main.js` (entry point, not in `modules/`)
- CSS: `main.css` in `src/styles/`
- HTML: `index.html` at project root

**Functions:**
- PascalCase for constructor-like: Not used (no classes)
- camelCase for all functions: `renderRow()`, `handleRefresh()`, `calcTargetQuantities()`, `fmtBRL()`
- Named exports: `export function setStatus() {...}` (`src/modules/ui.js:6`)
- Default exports: None used

**Variables:**
- camelCase for locals: `agora`, `successCount`, `somaPesos`
- UPPER_SNAKE_CASE for module-level constants: `DEFAULT_ATIVOS` (`src/modules/state.js:4`)
- Export via `export let`: `export let ATIVOS = [...]` (`src/modules/state.js:34`)
- Hungarian notation: Not used

**Types (Asset Objects):**
```js
{ ticker: string, setor: string, cat: 'div'|'cres', peso: number }
```
- `ticker`: Stock/asset ticker (e.g., `'ITUB4'`)
- `setor`: Business sector (e.g., `'Bancos'`)
- `cat`: Category — `'div'` (dividends) or `'cres'` (growth)
- `peso`: Target allocation weight as percentage (e.g., `6` for 6%)

## Where to Add New Code

**New Feature / Module:**
1. Create new file in `src/modules/`, e.g., `src/modules/notifications.js`
2. Use named exports: `export function showNotification(msg) {...}`
3. Import in `src/main.js` and add UI bindings in `init()`

**New UI Component:**
1. Add HTML markup in `index.html` (inside `.app` div or as new modal)
2. Add CSS in `src/styles/main.css` (use CSS custom properties for theming)
3. Add rendering logic in `src/modules/ui.js` or inline in `main.js` handlers
4. Bind events in `init()` in `src/main.js`

**New Calculation / Business Logic:**
1. Add pure function to `src/modules/logic.js` — no side effects, no DOM
2. Import in `src/main.js` or `src/modules/ui.js` as needed
3. Keep formatting functions (`fmtBRL`, `fmtPct`) in `logic.js` for reuse

**New API Integration:**
1. Create or extend `src/modules/api.js`
2. Use `fetch()` with AbortController for timeout handling
3. Store results in `state.js` via the `prices` object or add new state variable
4. Call `saveState()` after updating to persist

**New Supabase Table/Feature:**
1. Supabase client is in `src/modules/supabase.js` — no changes needed there
2. Add queries in `src/modules/state.js` (for data sync) or `src/modules/auth.js` (for auth)
3. Update `syncFromSupabase()` if schema changes

**Utilities:**
- Shared pure utilities → `src/modules/logic.js`
- DOM utilities → `src/modules/ui.js` or inline in handlers
- Theme utilities → `src/modules/theme.js`
