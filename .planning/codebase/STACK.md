# Stack

## Core Technologies
- **HTML5**: Structural markup.
- **CSS3**: Custom styling with CSS Variables (CSS Custom Properties).
- **JavaScript (ES6+)**: Frontend logic, state management, and API interaction.

## UI & Styling
- **Vanilla CSS**: Used for the entire design system, including a dark theme with glassmorphism-like elements.
- **Typography**:
  - `DM Sans`: Primary UI font.
  - `DM Mono`: Monospaced font for financial values and tickers.
- **Google Fonts**: Hosted via CDN.

## APIs & Data Sources
- **BrAPI**: Used for fetching real-time stock and FII quotes (`brapi.dev`).

## Persistence
- **Web Storage API (localStorage)**: Used to persist asset quantities, weights, and the API token.
